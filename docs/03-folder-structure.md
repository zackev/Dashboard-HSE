# Folder Structure

```
frontend/
```

Berisi seluruh source code React.

Folder ini hanya bertanggung jawab terhadap User Interface.

---

## src/

Merupakan folder utama React.

Seluruh halaman aplikasi berada di sini.

---

## pages/

Berisi halaman utama aplikasi.

Contoh

Dashboard

Permit

Inspection

Incident

Document

---

## components/

Berisi komponen yang dapat digunakan ulang.

Misalnya

- Table
- Modal
- Card
- Sidebar
- Header

---

## services/

Berisi komunikasi API menggunakan Axios.

Semua request HTTP dilakukan melalui folder ini.

---

## contexts/

Berisi Global State.

Contoh

Authentication

Theme

Language

---

## assets/

Berisi icon, gambar dan asset lainnya.
