# HSE Dashboard Documentation

Selamat datang di dokumentasi **HSE Dashboard**.

Dokumentasi ini dibuat sebagai panduan bagi developer, administrator sistem, maupun perusahaan yang akan melakukan implementasi, maintenance, atau pengembangan lebih lanjut terhadap aplikasi.

---

# Tujuan Dokumentasi

Dokumentasi ini bertujuan untuk:

- Memahami arsitektur aplikasi
- Memahami struktur source code
- Memahami alur data
- Memahami business process setiap modul
- Mempermudah onboarding developer baru
- Menjadi referensi saat maintenance
- Menjadi panduan saat menambah fitur baru

---

# Tech Stack

## Frontend

- React
- Vite
- TailwindCSS
- Axios
- React Router
- Lucide Icons

## Backend

- Laravel 11
- Sanctum
- Eloquent ORM

## Database

- MySQL
